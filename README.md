# JITHU KANNAN T J | Portfolio

A premium, cinematic personal portfolio website built with a warm sunset theme. Designed for an Electrical & Electronics Engineering student specializing in AI, Embedded Systems, and IoT.

## Features
- **Sunset Theme**: Warm orange-to-purple gradient color palette
- **Responsive**: Mobile-first design with clean, grid-based layout
- **Interactive**: Smooth scroll animations, 3D card tilt effects, typing animation, glassmorphism UI
- **Sections**: Home, About, Education, Skills, Projects, Timeline, Contact
- **Tech Stack**: HTML5, CSS3, JavaScript (Vanilla)

## Local Setup
1. Clone the repository: `git clone https://github.com/JITHUKANNAN-TJ/portfolio.git`
2. Open `index.html` in your browser.

## Deploy (GitHub Pages)
1. Go to your repository on GitHub: [portfolio](https://github.com/JITHUKANNAN-TJ/portfolio)
2. Click **Settings** > **Pages**
3. Under **Branch**, select `main` and click **Save**
4. Your site will be live at `https://JITHUKANNAN-TJ.github.io/portfolio/`

## Project Structure
- `index.html` — Main structure and all sections
- `style.css` — Sunset theme styling, glassmorphism, animations
- `main.js` — Scroll logic, typing effect, 3D tilt, interactivity
